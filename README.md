# Test API ISS

# Description
Ce programme est une application python en console permettant d'afficher la position de l'ISS ainsi que ses passagers.

# Installation
Ce projet utilise la version 3.14 de Python et le paquet requests.

# Utilisation
Le programme affiche dans la console de l'utilisateur 2 choix:
- Afficher les coordonnées de l'ISS,
- Afficher le nombre d'astronautes dans l'ISS ainsi que leur nom.
